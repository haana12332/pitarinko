# ぴたりんこ！ (Pitarinko!)
> [cite_start]**「暖簾（のれん）」が導く、新しい街歩きと店選びの体験** [cite: 2]

[cite_start]「ぴたりんこ！」は、ソニーのSpresenseとWeb技術を組み合わせ、飲食店の「入り口」と「出口」をインタラクティブに変えるプロダクトです [cite: 10][cite_start]。観光客の不安を解消し、店舗の集客とファン化を促進します [cite: 13, 15]。

---

## 📌 Vision & Problem (なぜ作ったのか)
[cite_start]観光地において、多くの旅行者が「スマートフォンの地図と睨めっこしてしまい、街の雰囲気を見落とす」「個人経営店の雰囲気が分からず入るのが怖い」という課題を抱えています [cite: 71, 73]。

* [cite_start]**ユーザーの痛み**: Google Mapの経路案内（64%）や写真（50%）を頼りにする一方で [cite: 78, 80][cite_start]、実際の雰囲気が伝わらず「思っていたのと違う」というミスマッチが発生 [cite: 90]。
* [cite_start]**店舗の課題**: 認知されるきっかけが少なく、新たなエンタメ性や集客のフックを必要としている [cite: 101]。

[cite_start]私たちは、日本の伝統的なインターフェースである**「暖簾」**に着目しました [cite: 13][cite_start]。暖簾をデジタル化することで、街の風景に溶け込みながら、直感的なナビゲーションとフィードバックを実現します [cite: 10, 14]。

## ✨ Core Features (ユーザー体験)

### 1. Welcome Interaction (手招きする暖簾)
[cite_start]ユーザーがアプリを使用して特定の店舗を探し、実際の店舗に近づくと、暖簾が自動で動き出します [cite: 2]。
* [cite_start]**体験**: まるで暖簾が「手招き」しているような動きを見せ、観光客に「おもしろさ」と目的地に辿り着いた「安心」を届けます [cite: 15]。
* [cite_start]**技術**: SpresenseでGPS距離を比較し [cite: 20][cite_start]、モーターで暖簾の軸を回転させることで、上下の動作を繰り返します [cite: 181, 182]。

### 2. Gesture Feedback (くぐるだけの直感評価)
[cite_start]退店時に暖簾をくぐる際の「体の動き」に応じて、お店の評価を自動で送信します [cite: 2, 28]。
* [cite_start]**体験**: 評価をわざわざ入力する手間を省き、店を出るという自然な動作を新しい体験に変えます [cite: 26, 28]。
* [cite_start]**技術**: Spresenseカメラによる画像認識（Edge AI）を活用 [cite: 33, 34][cite_start]。右手・左手・何もしない状態を各150データずつ学習させたモデルで、高精度な評価判別を行います [cite: 185, 188]。

### 3. Vibe-driven UI (雰囲気で選べるアプリ)
[cite_start]若年層が慣れ親しんだSNSのようなUIで、他のユーザーが投稿した写真や評価付きリール動画を閲覧できます [cite: 113, 158]。
* [cite_start]**体験**: 画面の文字を読まずとも「雰囲気」で伝わるUIを目指し [cite: 147][cite_start]、ボタンの「ぷにっ」としたフィードバックなど、利用時の満足度も追求しました [cite: 156]。

## 🛠 System Architecture

[cite_start]エッジ（Spresense）とクラウド（Firebase）を中継サーバーを介して連携させることで、柔軟なデータ処理が可能な設計にしています [cite: 160, 161]。

| コンポーネント | 使用技術 | 役割 |
| :--- | :--- | :--- |
| **Edge Device** | **Sony Spresense** | [cite_start]GPS取得、モーター制御、カメラ画像認識 [cite: 33, 162, 166] |
| **Backend** | **Server (Node.js)** | [cite_start]GPS用・評価用サーバーをそれぞれ立て、送受信の仲介・頻度を制御 [cite: 160, 161] |
| **Cloud** | **Firebase** | [cite_start]DB/ストレージ機能を用い、評価データと写真情報を保存 [cite: 192] |
| **Front-end** | **Web App** | [cite_start]地図ナビゲーションおよび、投稿写真の閲覧機能 [cite: 122, 124] |

## 🚀 Implementation Details (実装の工夫)

* [cite_start]**データ収集の一貫性**: AIによる画像処理の高精度化のため、撮影時にモニターにグリッド線を表示し、本番環境に近い条件で学習データを収集しました [cite: 189, 190]。
* [cite_start]**直感的なナビゲーション**: 既存の地図ナビアプリを分析し、一目で「案内中」であることが伝わる色使いやアイコン配置を工夫しています [cite: 146, 147]。
* [cite_start]**スケーラブルな通信**: 各中継サーバーを介することで、データ送受信の間に処理を加えたり、更新頻度を動的に変更できる構成にしました [cite: 161]。
